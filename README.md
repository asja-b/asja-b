## 🚀 Projects

### [SafeHer](https://github.com/asja-b/safeher)
Interactive web app teaching girls (11-16) to recognize online dangers through realistic social media simulations. **2nd place + Best Idea** at Digital Divas Hackathon 2026.
`JavaScript` `HTML/CSS` `UI/UX`

### [GirlTHing Frontend](https://github.com/asja-b/girlthing-frontend)
Angular assignments from the GirlTHing Full Stack Development Program, covering components, routing, services and more.
`Angular` `TypeScript`

### [IoT Digital Wardrobe](https://github.com/asja-b/iot-digital-wardrobe)
Smart IoT system built with ESP32 and DHT11 that reads temperature and humidity in real time, displays clothing recommendations on an LCD screen, and syncs to Firebase for display on a web app.
`ESP32` `Arduino` `Firebase` `JavaScript` `HTML/CSS`

### [KBeauty - UX Design Project](https://github.com/asja-b/hci-kbeauty)
Complete UX design project for a Korean cosmetics web shop with integrated ingredient analysis. Includes user research, HTA diagram, use case diagram, PMF matrix, and a high-fidelity Figma prototype.
`Figma` `UX Research` `HTA` `Use Case` `Prototyping`

### [Programming 3 - Exam Tasks & Solutions](https://github.com/asja-b/programming3-exams)
Collection of exam tasks and solutions from the Programming 3 course covering WinForms applications with Entity Framework and SQL Server.
`C#` `.NET` `WinForms` `Entity Framework` `SQL Server`
