## 🚀 Projects

### [IoT Digital Wardrobe](https://github.com/asja-b/iot-digital-wardrobe)
Smart IoT system built with ESP32 and DHT11 that reads temperature and humidity in real time, displays clothing recommendations on an LCD screen, and syncs to Firebase for display on a web app.  
`ESP32` `Arduino` `Firebase` `JavaScript` `HTML/CSS`

### [KBeauty — UX Design Project](https://github.com/asja-b/hci-kbeauty)
Complete UX design project for a Korean cosmetics web shop with integrated ingredient analysis. Includes user research, HTA diagram, use case diagram, PMF matrix, and a high-fidelity Figma prototype.  
`Figma` `UX Research` `HTA` `Use Case` `Prototyping`
